# Solución al Desafío de Frontend Mentor: Componente de Introducción con Menú Responsivo

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Project Tracking Intro Component** de Frontend Mentor. El objetivo era crear una página estática con un menú responsivo que se adapte a diferentes tamaños de pantalla, especialmente en dispositivos móviles.

**Desafío de Frontend Mentor:** [Project Tracking Intro Component](https://www.frontendmentor.io/challenges/project-tracking-intro-component-5d289097500fcb331a67d80e)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/project-tracking-intro-components-master.github.io/)

## Descripción del Proyecto

Este proyecto es una página estática que presenta una introducción a un servicio de seguimiento de proyectos. La página incluye:

- Un **menú de navegación responsivo** que se convierte en un menú hamburguesa en dispositivos móviles.
- Una sección de introducción con un título, descripción y botones de llamada a la acción (CTA).
- Una imagen ilustrativa que complementa el contenido.

La funcionalidad principal es el menú responsivo, que se activa cuando la ventana del navegador se reduce a un tamaño móvil. El menú se abre y cierra con una animación suave, implementada con JavaScript.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: Flexbox y Grid para el diseño responsivo.
- **Animaciones**: Transiciones CSS para suavizar la apertura y cierre del menú.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
